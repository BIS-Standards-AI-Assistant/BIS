# UI/UX Principles

1. **Service before AI** — lead with the user task, not the technology.
2. **Evidence before confidence** — show the source instead of relying on scores.
3. **Search before conversation** — the core interaction is standards discovery, not chat.
4. **Clarify instead of hallucinating** — ask for missing product attributes.
5. **Explain recommendations** — every major standard needs a relevance reason.
6. **Separate fact from inference** — clearly distinguish verified evidence, interpretation, and uncertainty.
7. **Minimize cognitive load** — plain language first, technical detail second.
8. **Never overclaim certification** — AI guidance does not itself establish official certification.
9. **Keep sources visible** — citations should be one interaction away.
10. **Preserve user context** — show structured product interpretation so users can correct it.
11. **Design failures explicitly** — no results, insufficient evidence, service unavailable, ambiguity.
12. **Government-service mindset** — stable, predictable, transparent, accessible.
13. **Progressive disclosure** — answer first, technical evidence on demand.
14. **Every screen has a next action** — search again, view, inspect, compare, explore, continue.
