# UI Accessibility

Accessibility is a product requirement.

## Requirements
- semantic HTML
- keyboard navigation
- visible focus
- correct form labels
- accessible error/loading messages
- sufficient contrast
- meaningful link text
- logical heading hierarchy
- appropriate alt text
- no color-only communication
- mobile-friendly touch targets

## Search
Label the field, support keyboard submission, expose errors, preserve input after failure.

## Evidence
Evidence panels must be keyboard accessible, readable, and clearly identify source metadata.

## Navigation
Desktop and mobile navigation must be keyboard usable.

## Motion
Respect prefers-reduced-motion.

## Testing
Perform keyboard walkthrough, accessibility inspection, mobile inspection, and focus-order review.
