# UI Review Checklist

## Government credibility
- [ ] No permanent dashboard sidebar
- [ ] Full-width institutional navigation
- [ ] BIS identity is clear
- [ ] Restrained visual language
- [ ] No AI-slop aesthetics
- [ ] No fabricated government content

## Homepage
- [ ] Main service is obvious
- [ ] Search is primary
- [ ] Examples are clear
- [ ] Actions are understandable
- [ ] No unsupported metrics

## Search/query
- [ ] Results readable
- [ ] Relevance explained
- [ ] Evidence discoverable
- [ ] Clarification works
- [ ] No chat-clone behavior
- [ ] Useful empty/error states

## Standard details
- [ ] Identity
- [ ] Scope
- [ ] Supported information
- [ ] Evidence
- [ ] Related standards where supported
- [ ] No fabricated metadata

## Truthfulness
- [ ] No fake standards
- [ ] No fake certification requirements
- [ ] No fake testing requirements
- [ ] No fake announcements
- [ ] No fake statistics
- [ ] No fake confidence values

## Accessibility
- [ ] Keyboard navigation
- [ ] Focus states
- [ ] Semantic headings
- [ ] Labels
- [ ] Contrast
- [ ] Mobile touch targets

## Engineering
- [ ] No console errors
- [ ] No hydration errors
- [ ] TypeScript passes
- [ ] Lint passes
- [ ] Backend contracts preserved
