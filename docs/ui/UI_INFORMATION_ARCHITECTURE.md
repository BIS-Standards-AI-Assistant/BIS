# UI Information Architecture

## Primary navigation
Recommended:
- Home
- Standards
- Certification
- Testing
- Resources
- e-Services
- About BIS

Only expose destinations actually supported by the application.

## Core routes
Adapt to the existing repository:
- /
- /search
- /standards
- /standards/[id]
- /compare
- /query

## Homepage
Service proposition → standards search → examples → service actions → verified updates → recent activity when available → official resources → footer.

## Search
Query → supported filters → results → relevance explanation → evidence → pagination if needed.

## Query workspace
User query → interpretation → clarification if needed → candidate standards → evidence → testing → certification information → next steps.

Do not render the workflow as a chat transcript.

## Standard detail
Breadcrumb → identity → scope → why relevant → supported requirements → testing → certification information → related standards → evidence → source.

Only render fields that actually exist.

## Compare
Select standards → comparison table → sourced differences → evidence.

## Footer
Use official institutional links only when configured and verified.
